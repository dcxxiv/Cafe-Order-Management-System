# Cafe-Order-Management-System

## Project Overview
This is a simple C++ program to manage cafe orders.  
Users can add, view, update, and cancel orders.  
All data is saved to a file for persistence.

## Team Members & Roles
- Hamna – Menu module (25021519-155)  
- Rahma Noor – Order module (25021519-239)  
- Zuha Fatima – Delivery module (25021519-056)  

## Features
- Display cafe menu  
- Add new orders  
- Show all orders with total price  
- Update existing orders  
- Cancel orders  
- File handling for saving orders  
- Input validation  

## Files
- `src/main.cpp` → main program  
- `src/menu.cpp` → menu functions  
- `src/order.cpp` → order functions  
- `src/delivery.cpp` → delivery/cancel order functions  
- `docs/project_description.pdf` → project details
